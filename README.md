# Holiday Adventure

假期 2D 横版闯关游戏的第一版原型。

## 运行

1. 安装 Godot 4.6.3 Standard。
2. 启动 Godot，点击“导入”。
3. 选择本目录中的 `project.godot`。
4. 打开项目后按 `F6` 或右上角运行按钮。

## 操作

- 左右移动：`A / D` 或左右方向键
- 跳跃：`Space / W / ↑`
- 提前松开跳跃键可以进行短跳
