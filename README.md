# Holiday Adventure

2D 横版像素动作游戏，包含单人闯关、30 波挑战竞技场、地图编辑器和多人 PvP/PvE。

当前试玩版本：`v0.9.6`

## 运行

1. 安装 Godot 4.7 Standard。
2. 启动 Godot，点击“导入”。
3. 选择本目录中的 `project.godot`。
4. 打开项目后按 `F6` 或右上角运行按钮。

也可以从 GitHub Releases 下载 Windows 版，解压后直接运行 `HolidayAdventure.exe`。

## 操作

- 左右移动：`A / D` 或左右方向键
- 跳跃：`Space / W / ↑`
- 提前松开跳跃键可以进行短跳
- 普通攻击：`J` 或鼠标左键
- 连续攻击：连续按三次攻击键
- 冲刺：`K` 或 `Shift`
- 格挡：`S / ↓`
- 魔法：按 `L` 施放，长按 1 秒或 3 秒蓄力
- 测试强化：`O`
- 暂停菜单：`Esc`

- 怪物攻击阶段、动画计时、Boss 招式、部位生命、特殊状态和召唤物均参与联机同步
- 敌方箭矢、法球、激光与地面危险区使用独立网络编号，并可靠同步生成和销毁
- 联机 PvE 的敌方伤害、减速、虚弱、中毒和眩晕由主机判定并同步到受击玩家
- 合作玩家倒地后由主机统一复活，保留本局已经获得的强化构筑
- 开始菜单可选择单人或多人模式，多人模式支持输入 IP 与端口
- 联机玩家之间可使用近战和法术互相攻击
- 同步攻击挥剑、斩击、冲刺残影和法术特效
- 每个肢体带血量状态点：高于 50% 为绿色，低于 50% 为黄色，低于 20% 为红色
- 支持 `--server --port=7000` 专用服务器模式，启动后使用 PvP 竞技场地图
- 多人主机可选择小型废弃大厅或宽 2200 像素的大型 PvP 竞技场
- PvP 的攻击、魔法命中、肢体血量与肢体破坏由主机统一判定并同步
- 玩家初始总生命为 50，初始近战攻击力为 3，基础魔法伤害为 2
- 每次升级从攻击、攻速、移速、二段跳、攻击范围、肢体生命、魔法等强化中随机抽取三项
- 强化收益：攻速 +20%、移速 +30%、范围 +20%、全肢体生命 +2、魔法上限 +20、回魔 +50%、冲刺冷却 -15%
- 大厅和大型竞技场使用独立场景分组与独立碰撞体，切换地图时会完整关闭另一张地图的碰撞
- 完美格挡只反制近战，使攻击者 1 秒内无法移动和攻击；持续格挡免疫魔法
- 普通攻击前两段拼刀只取消伤害，双方第三段互拼才会硬直；下段只能与下段拼刀，且下段无视格挡
- 缺血时每 6 秒严格按身体、头部、左手、右手、左脚、右脚恢复 1 点；轮到断肢并从 0 恢复到 1 时重新长出，快速再生可将间隔降至 3 秒
- 近战攻击可以击碎飞行中的魔法弹
- 标题菜单提供显示设置：1080p/2K 分辨率，以及 60/120/240 帧率上限
- Godot 编辑器的“嵌入游戏”会锁定预览窗口尺寸；测试分辨率时需关闭嵌入运行或使用导出的 EXE
- 多人游戏支持自定义玩家名字、头顶独立血量、实时延迟显示和双向 PvP 伤害
- 多人头像会缩放为 48×48 PNG、转换为 Base64 后同步到所有玩家头顶
- 文本输入结束后会清理方向键状态；回血不再显示飘字，完美格挡会显示“格挡！”
- `S/↓` 举盾格挡：前 0.2 秒完美格挡会封锁近战攻击者的移动和攻击 1 秒，之后近战减伤 50%，举盾期间免疫魔法
- 格挡时移速降低 70% 且无法转向；任一手臂损毁后盾牌消失并禁用格挡
