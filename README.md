# Holiday Adventure

假期 2D 横版闯关游戏的第一版原型。

当前试玩版本：`v0.2.0`

## 运行

1. 安装 Godot 4.7 Standard。
2. 启动 Godot，点击“导入”。
3. 选择本目录中的 `project.godot`。
4. 打开项目后按 `F6` 或右上角运行按钮。

## 操作

- 左右移动：`A / D` 或左右方向键
- 跳跃：`Space / W / ↑`
- 提前松开跳跃键可以进行短跳
- 普通攻击：`J` 或鼠标左键
- 连续攻击：连续按三次攻击键
- 冲刺：`K` 或 `Shift`
